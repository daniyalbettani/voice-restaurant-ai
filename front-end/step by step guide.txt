----How Traditional Websites Work vs. React----
In older, traditional websites, every time you click a link, your browser has to talk to the server, download a completely new HTML file,
and the entire screen goes white for a second while it reloads.

React does something much cooler. It creates a Single Page Application (SPA). This means the browser only ever loads one actual web page.
When you click a button to go to a new screen, React doesn't reload the page—it just instantly swaps out the code on the screen.
It feels incredibly fast, almost like a mobile app!

---Why do we need React Router?---

Because React never actually refreshes the page, the URL bar at the top of your browser wouldn't naturally change.
You would be stuck on http://localhost:5173/ forever, even if you clicked a button to open the Kitchen Dashboard.

React Router is a library (a pre-written tool) that does two magic things:
.> It safely changes the text in your URL bar (like adding /admin) without causing the page to reload.
.> It watches that URL bar. If it sees /admin, it instantly says, "Aha! Take the Customer code off the screen and put the Admin code on the screen."

// 1. We import three specific tools from the 'react-router-dom' library we just installed

	import { BrowserRouter, Routes, Route } from 'react-router-dom'
    	<BrowserRouter> // BrowserRouter: This is the "Engine". It wraps your whole app and constantly watches the URL bar.
    	
      
      	<Routes> {/* Routes: This is like a "Switchboard". It holds all your possible page rules. */}
      
        
        {/* Route: This is an individual rule. */}
        {/* It says: "IF the path is exactly '/' (the home page), THEN show the <CustomerPage />" */}
        <Route path="/" element={<CustomerPage />} />
        
        {/* It says: "IF the path is '/admin', THEN show the <AdminDashboard /> instead" */}
        <Route path="/admin" element={<AdminDashboard />} />
